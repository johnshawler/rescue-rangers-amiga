# Rescue Rangers native Amiga recovery

The active source is on the [clearly labeled recovery branch](https://github.com/johnshawler/rescue-rangers-amiga/tree/recovery/title-baseline-2026-11-10).

It preserves the reproducible early title/menu source and independently tested new development. The later playable development binaries do not have recovered gameplay/audio source in this repository.

Cartridge, firmware, extracted assets, captured state and compiled game binaries are excluded. This is incomplete development work, not a full-game or full-speed release.
