## Publication contract

The production adapter changes no RAM, resource, stack, journal, mapper/runtime metadata, native register or physical status flag. N/V/U/D/I/Z/C are retained exactly; only the B bit (0x10) is cleared in context byte5. Native A6 is saved/restored; D0 remains the predecessor's result. There is no persistent shadow state or larger runtime ABI. The host trace captures the full raw context immediately before the existing canonical-status instruction, purely for diagnostics.

For each adapted helper140 call, a private original-only replay starts from the exact native input context/RAM and compares full raw output, ordered effects and RAM before published status is checked. The live original execution and complete original-first persistent chain remain separately compared. This is an explicit interface convention, not a hidden relaxation of the raw module contract. Cumulative status tests verify that eliminating the nonphysical B convention does not change subsequent stack bytes or real flags across PHP/PLP and interrupt/return operations.
