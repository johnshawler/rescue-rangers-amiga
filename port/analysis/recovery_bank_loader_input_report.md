## Reproduction and boundaries

Set VASM to the approved vasmm68k_mot and PYTHONPATH to the installed machine68k/py65 location, with PYTHONDONTWRITEBYTECODE=1. Run bash port/tools/recovery_bank_loader_input_public.sh for recursive verified source-only restore and public tests with cartridge/oracle access denied. For private status tests, run python port/tests/recovery_bank_loader_input_status_test.py with the private initial object-boundary directory. For continuous replay, create an empty output directory, set RECOVERY_PRIVATE_SNAPSHOT_DIR to it and PROBE_PAD=1 or129, then run python port/tests/recovery_bank_loader_input_rom.py default. Expected termination is an assertion recording the unsupported C0BF entry, not a success claim.

No target builder, renderer, audio backend, disk or public repository was changed. This is host semantic evidence only. Independent review of this new composition is required. NonzeroF6, other raw-status paths, longer moving histories and target speed remain outside this milestone.
